# Дневник фридайвера

Простой веб-дневник тренировок по фридайвингу.

Цель MVP — сделать цифровую версию бумажного дневника, где пользователь может сохранять тренировки и открывать их с разных устройств.

## Текущий этап

Проект переходит от локального хранения в браузере к веб-версии с Supabase.

Главный сценарий:

Пользователь вошёл → добавил тренировку → запись сохранилась → открыл дневник с другого устройства → запись на месте.

## Supabase

Таблица тренировок:

`public.trainings`

Поля:

- `id`;
- `user_id`;
- `date`;
- `type`;
- `coach`;
- `mood`;
- `training`;
- `notes`;
- `total_volume`;
- `dives`;
- `created_at`;
- `updated_at`.

RLS включён. Каждый пользователь должен видеть только свои записи.

## Безопасность ключей

В проект можно добавлять:

- Project URL;
- Publishable key.

Нельзя добавлять:

- database password;
- secret key;
- service_role key;
- JWT secret;
- пароли.

## Безопасность фридайвинга

Приложение — дневник, а не замена инструктору, врачу или напарнику.

Не тренируйтесь в воде в одиночку. Тренировки в воде должны проходить в безопасных условиях и с напарником.
